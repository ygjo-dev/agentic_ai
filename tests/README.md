없도록 1:1 로 맞춰 두었다. 각 파일 첫 줄에도 대상 경로가 적혀 있다.

```
python -m pytest tests -q
```

`demo/ui/` 를 보는 테스트는 없다. 화면은 시연할 때마다 바뀌므로 붙들어 두면
바꿀 때마다 테스트를 갱신하는 일만 반복된다. 대신 그 아래의 그리기 · 좌표 ·
경로 계산이 전부 `demo/api/graph_svg/` 로 내려와 있고, 그쪽은 촘촘히 검증한다.

## `graph_svg/` 가 지키는 것

여기 있는 단언 대부분은 **몇 주에 걸쳐 실측으로 알아낸 성질**이다. 지우면
다시 알아낼 방법이 없으므로 함부로 손대지 않는다.

| 성질 | 어기면 |
|---|---|
| 어떤 강조 조합에서도 노드 좌표가 같다 | 후보를 좁힐 때마다 지도가 튄다 |
| 캔버스 크기가 안 변한다 | 축소 배율이 바뀌어 그래프가 커졌다 작아졌다 한다 |
| 노드를 등록해도 기존 노드가 0.0000pt | "새 노드가 어디 붙었나" 대신 "화면이 리셋됐다" 로 보인다 |
| `inputscale=72` | 좌표 왕복이 72배로 어긋난다 (실측 delta 14657) |
| 핀이 있으면 `overlap` 금지 | 고정을 무시하고 388~710pt 밀어낸다 |
| 회전은 최초 배치에만 | 두 번 걸리면 지도가 뒤집힌다. **짝수 번째에는 상쇄돼 숨는다** |
| 배치가 결정적이다 | 켤 때마다 다른 지도가 나온다 |
| 순번은 경로가 하나일 때만 · 같은 엣지를 두 번 지나면 이어 붙인다 | 라벨이 겹쳐 읽을 수 없다 |
| `constraint=false` 를 안 쓴다 | 브라우저 렌더러가 레이아웃을 끝내지 못한다 |
| 기본 인자 출력이 한 글자도 안 변한다 | 리팩터링 안전망이 사라진다 |
| 키워드 인자 목록 검사 | 인자를 더하고 위 불변 테스트에 빠뜨리면 여기서 먼저 터진다 |
| `layout_store` 가 어떤 입력에도 예외를 안 올린다 | 좌표 파일 하나 때문에 시연 화면이 죽는다 |

## 여기 없는 것

**DOT 문자열의 색 · 굵기 · 화살표 유무 · 라벨 형식** 을 검사하는 테스트는 두지
않는다. 시연 화면은 계속 바뀌고, 그때마다 깨져서 갱신하는 일만 반복된다.
회귀는 "Graphviz 가 출력을 받아들인다"(실제 온톨로지 포함) 같은 통합 검사가 잡는다.

## 저장소를 더럽히지 않는다

`registry/` 는 실제 YAML 파일을 쓴다. 반드시 임시 디렉터리로 격리하거나
`reset_to_init()` 으로 되돌린다. `pytest` 를 돌린 뒤 저장소에 노드가 남아 있으면
개수를 세는 다른 테스트들이 연쇄로 깨진다.
